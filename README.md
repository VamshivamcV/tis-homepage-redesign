# Tula's International School (TIS) - Homepage Redesign

A modern single-page landing experience for Tula's International School, redesigned for stronger visual hierarchy, premium school branding, and smoother conversion-focused interactions.

## 🛠️ Tech Stack
- Framework: Next.js 16
- Styling: Tailwind CSS
- Animation: Framer Motion
- Icons: Lucide React
- Deployment: Vercel

## ✨ Standout Features Implemented
1. Custom Cursor: a subtle animated cursor for desktop devices with touch/mobile fallback.
2. Scroll Progress Bar: a fixed top progress indicator that reflects page depth.
3. Scroll Reveal Animation: sections animate into view with staggered motion.
4. Theme Toggle: polished light/dark mode switch with local storage persistence.
5. Responsive Layout: optimized for mobile, tablet, and desktop screens.

## Getting Started

First, run the development server:

```bash
npm run build
```

The project is configured to compile cleanly in a production build with the required Next.js and Tailwind stack.
